# Topics

One map per topic, named `<topic>.md`. A map sets the order of learning and tracks progress. It links to concept notes in `../learn/` and to labs in `../../labs/` rather than holding knowledge itself.

~~~markdown
# <Topic>

Started YYYY-MM-DD.

## Goal
What understanding looks like for this topic, and the brief it should produce.

## Concepts
| # | Concept | Why it matters | Source | Status |
| --- | --- | --- | --- | --- |
| 1 | <concept> | <one line> | <link to material> | not started · in progress · done |
~~~

A concept counts as done when it has a note in `docs/learn/` and a lab that reproduces its key behaviour.
