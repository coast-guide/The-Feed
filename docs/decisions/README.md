# Decisions

Architecture decision records in the minimal [MADR 4](https://adr.github.io/madr/) shape, named `NNNN-<slug>.md` and numbered in order. An accepted record is never edited; a new record supersedes it, and the two link to each other.

~~~markdown
# NNNN · <decision as a short statement>

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context and problem

## Considered options

## Decision

## Consequences
~~~
