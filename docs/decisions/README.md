# Decisions

Architecture decision records in the minimal [MADR 4](https://adr.github.io/madr/) shape, named `NNNN-<slug>.md` and numbered in order. An accepted decision is never changed: a new record supersedes it, and the two link to each other. Corrections that leave the decision intact, such as wording or broken links, are allowed.

~~~markdown
# NNNN · <decision as a short statement>

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context and problem

## Considered options

## Decision

## Consequences
~~~
