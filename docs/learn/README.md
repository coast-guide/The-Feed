# Learn

Distilled knowledge, one concept per file, named `<concept>.md` in kebab-case. Each note is the only home for its concept; other files link to it.

~~~markdown
# <Concept>

As of YYYY-MM-DD.

## What
One paragraph.

## Why it matters in production

## How it works
The mechanism, only as deep as needed to predict behaviour.

## What breaks
Failure modes and gotchas.

## Evidence
Labs and primary sources, dated.

## Open questions
~~~
